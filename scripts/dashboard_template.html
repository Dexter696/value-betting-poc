stake = (edge ÷ (odds − 1)) × kelly fraction  —  sized per bet from that bet's own entry edge and odds (a negative edge clips to 0, never a short). At fraction 1.0 this is full, unscaled Kelly - not the same as flat staking, since it still varies stake per bet instead of using a fixed size. Lower fractions scale every bet's stake down proportionally to reduce variance (quarter-Kelly, 0.25, is the more common conservative default).
